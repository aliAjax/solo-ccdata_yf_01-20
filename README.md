# Pixel Loom

无需后端的像素动画编辑器演示。打开 `index.html` 即可使用；支持像素画笔/橡皮擦/取色、帧管理、洋葱皮、撤销重做、本地保存和 PNG 导出。

## 多轨音频

- **导入多段本地音频**：每个文件自动成为一条音轨，片段显示波形。
- **片段编辑**：拖动移动（可跨轨）、拖动两端裁剪、复制、删除；可调音量、静音、淡入淡出。
- **节拍标记**：双击标尺或在播放头处添加，可拖动、选中后删除；开启「吸附」后片段与播放头对齐到标记和帧网格。
- **播放**：音画同步（音频时钟驱动帧），支持静音预览与循环区间（在标尺顶部循环带拖动设置）。
- **撤销重做**：所有音频编辑与像素编辑进入同一历史。
- **持久化**：保存后音轨结构存入 localStorage；刷新后结构恢复，通过「重新关联」按钮指回原音频文件即可继续编辑。
- **导出 WebM**：合并混音与动画画面实时录制为 WebM；浏览器不支持 WebM 或没有可混音的音频时会拒绝导出（不会生成无声文件）。
